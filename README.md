This repository contains **40+ hands-on TypeScript assignments** designed to strengthen programming fundamentals, problem-solving skills, and TypeScript best practices.

Each assignment focuses on a specific concept and provides practical implementation to help developers gain confidence in writing scalable, maintainable, and type-safe applications.

Whether you're a beginner learning TypeScript or an experienced JavaScript developer transitioning to TypeScript, these exercises provide excellent practice.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Muskanateeq/Typescript_assignment.git
```

Move into project

```bash
cd Typescript_assignment
```

Install dependencies

```bash
npm install
```

Compile TypeScript

```bash
tsc
```

Run JavaScript

```bash
node index.js
```

Or run directly using ts-node

```bash
npx ts-node index.ts
```
